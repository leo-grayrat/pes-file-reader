## 6. 结论与字段语义假定

- **财务字段模板化（本次最强发现）**：v3/v4/v5/v6/v8 的**值集合跨存档 100% 完全一致**（4a：99/99、76/76、67/67、82/82），而 f2_hi(球员) 跨存档 **0% 重叠**、同一 (球员,金额) 对零重复。
  → 三份独立生涯存档的事件表，财务字段用的是**同一套模板值**，只有球员引用随各档不同——
  事件表不是「各档独立模拟的随机转会流」，更像**模板化市场事件**（财务参数固定、球员槽位按档填充）。
- **v3 金额判定需谨慎**：中位数 41.9 万欧、P90 158 万欧，符合转会费量级；但存在 v3×100 达 3690 亿欧的极端值（见 §2c），疑似打包值/哨兵，不能把 v3 全量当金额。
- **v1_status**：三档均 85:14 结构（v1=1 共 42 行），v1=1 的金额全部 ≤139 万欧、分布规整；v1=0 含全部异常大值 → 推测 v1=1 为「已签约/已结算」、v1=0 为「挂牌/在售」，仍需字段语义复核。
- **v7_flag=1 → v6 清空：成立**（空 = `0xFFFFFFFF`，**不是 0**）：v7=1 的 39 行 v6 **100%** 为哨兵、v7=0 的 258 行 **0%** 命中，完美互斥（§3）。此前按 `v6==0` 判定导致误判，已修正。
- **v4/v5/v6/v8**：值域 1e8~1e9，远超出「俱乐部 ID」量级；v6 与 v3/v5 有中等相关 (+0.40/+0.34)、v8 与 v6 负相关(-0.21)，其余接近 0 → 判定为打包值/指针/二级索引，非直接可读字段。
- **v2_raw**：与 idx 非单调、与所有数值字段几乎无关(≤0.05)，疑似散列/种子而非序号。
- **未依赖球员名**：以上结论全部基于数值字段，option file 41.1% 命名覆盖不构成分析前提。
